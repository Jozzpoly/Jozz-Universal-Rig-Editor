# Agent rules

- Authored truth is `RigDocument`; Three objects, source assets, preview state and runtime observations are projections or inputs, never automatic truth.
- Keep `src/kernel` dependency-free from React, Three, browser APIs and consumer runtimes.
- A normal feature should be a small vertical module with targeted tests. Do not add a framework, plugin system, ECS, asset database or generic runtime abstraction without a real consumer.
- Borrowed code does not import borrowed authority. M5/M6, JES schemas, VAW Blueprint and HomeScan scene state are not rig truth here.
- Source revision changes fail closed for binding claims; never silently retarget an authored frame.
- Camera/navigation is inspection infrastructure. Do not inherit gameplay camera clamps or restrictions into the workbench.
- Owner acceptance is scoped to what was actually inspected.
- Update or delete canonical docs instead of adding parallel plans/RFCs/handoffs.
